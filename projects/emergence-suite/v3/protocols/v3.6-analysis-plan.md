## Mechanical pilot-to-floor rule

The rule is frozen before the pilot and applies without contrast-specific
selection:

1. A nonzero effect is attainable only if its paired 95% interval carries the
   declared sign.
2. Every nonzero effect floor is exactly `0.50 * abs(pilot point estimate)`.
3. Every rate/recovery floor is exactly `0.90 * pilot point estimate`.
4. Calibration/proper-score ceilings equal the pilot point estimate plus
   `0.03`.
5. Exact identities use `1e-10`; equivalence uses the full 95% interval inside
   the theory-defined ROPE `[-0.01, 0.01]`.
6. No primary-length floor is transplanted to an information-budget sweep.

`0.018566762350958` nats/token: the full width of the deterministic 95%

public worlds (`[-1.89879339, -1.88022663]`, RNG seed 3606, 10,000
replicates). The criterion is V3 minus V2 lower CI `>= -margin` on common
worlds.
