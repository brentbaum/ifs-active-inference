# V3.0 frozen analysis plan

Stage 0 uses all seeds 3000000–3001999 for prior-predictive attainability.
Those seeds are permanently barred after thresholds are written to the
parameter block. Gate 2 uses the first 1,000 seeds in 3002000–3003999, once.
Accuracy is the fraction of fieldwise MAP values equal to the generating
field. Calibration is ten-bin ECE over the generating-value posterior.
Coverage is the fraction whose 95% highest-posterior set contains truth.
Exact log-probability parity uses tolerance 1e-10.

Gate 3 uses six same-sized public composition cells in 3004000–3006999:
identity-only, danger-only, causal-action absent/present, mixed cue/context
scope, mixed drift/recurrent dynamics, and two simultaneous modes without an
authored cross-mode interaction. The mixed temporal cell is compiled through
the standing R0 process grammar.

Gate 4 deletes, one at a time, the mode-count, context-count, edge, scope, and
dynamics productions. Each lesion must alter only its declared posterior
coordinate. Gate 5 varies slot bounds, cue count, missingness, code-length
scale, and generic concentration. Primary accuracy, calibration, coverage,
normalization, and custody are reported per cell; no robustness cells are
pooled.

Failures are retained verbatim. Gate progression stops at the first failed
gate. The sealed C-V30 block 4000000–4001999 remains closed.
