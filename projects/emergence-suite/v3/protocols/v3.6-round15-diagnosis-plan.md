## Layer A — retained-trace audits

### A1. Frozen-prior structure-draw audit

The joint truth category is the Cartesian product of the frozen V3.5 protect program (including its edge mask), cross-sign state, partner state, contact-response state, and frozen V3.2 temporal program. We report observed and expected complete-program frequencies, active-count frequencies, every protect edge, cross sign, partner, contact response when serialized, temporal fields, and all pairwise dependencies among these grouped truth features.

The omnibus statistic is Pearson's multinomial statistic over categories with positive expected mass. Its Monte Carlo percentile is the fraction of 2,000 exact-prior simulations whose statistic is at least the observed value, with the standard plus-one correction. We also report the observed multinomial log probability. Grouped marginal simultaneous intervals use the replicate-wise maximum absolute standardized deviation, so the intervals cover all listed marginals simultaneously. No KS statistic is used.

### A2. Complete-data joint identity

For each world, compare generator and scorer complete-data log joints in twelve fixed components: structure prior; cross-sign prior; partner/contact priors; mode path; root/identity emission; do(policy)-conditioned outcome emission; partner emission; contact-response emission; temporal-structure prior; context path; context emission; masking. Full and recombination tolerances are `1e-10`.

If any required native latent path, intervention, mask, or observation state was not serialized, the result is exactly `FAIL_APPARATUS_REQUIRED_NATIVE_PATH_STATE_NOT_SERIALIZED`. Missing state is never reconstructed from a seed.

### A3. Canonical-field semantics

The machine-readable role manifest freezes each field as latent, observable, intervention, mask/availability, or metadata and assigns exactly one generating/scoring factor to every observable. Code inspection and deterministic assertions test that latent `modes_input` is not presented as a mode observation; action and joint policy are `do(...)` inputs; held-out outcomes are not used in prefix fitting; masked context contributes one; adapters manufacture no observations; and each scored observation has one factor.

### A4. Truth/readout reconstruction

Independently decode the protect and temporal truth IDs and reconstruct active count, JOINT_POLICY_Y, all serialized load-bearing edges, and equivalence class. Independently marginalize the serialized full structure posterior to active-count and edge posteriors and independently sum exact-program masses into the serialized class map. Required agreement is `1e-12` (stricter than the ruled `1e-10`).

### A5. Calibration estimator replication

A standalone implementation that imports no runner computes ten-fixed-bin binary ECE, top-label ECE, macro classwise ECE, deterministic canonical-tie HPD coverage, Brier, log score, and world weighting from serialized values only. Agreement with the retained qualification record must be at most `1e-12`.

## Layer B — reduced exact path enumeration
