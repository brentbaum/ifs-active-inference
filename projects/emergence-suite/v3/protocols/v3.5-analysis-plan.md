## Amended generative and policy constructs

Every slot-indexed channel has three distinct states. An active slot uses its
mode-conditional likelihood. A dormant slot uses the frozen, candidate-common
`M_k=0` prior predictive for that channel. A masked channel contributes
likelihood exactly one. `None` means masked/unavailable only.

Partner inference is hierarchical. One global `q(L)` represents general
partner reliability. Generic mode-scoped support-response parameters
`theta_support[k]` use the existing `mode_specific` scope. Pre-contact partner
history informs `q(L)` but carries no information about which mode will
receive support. Only targeted befriending/support observations update the
mode-scoped response parameter. Trust remains a posterior-predictive query;
there is no per-mode trust object.

Stakes never alter emissions or any scientific posterior. They enter policy
utility only as `lambda_v`, the weight on posterior expected vulnerable-mode
cost under `do(joint_policy)`. The paired stakes assay holds observations,
`q(L)`, structure, parameters, and every policy-conditional predictive fixed.

Policy histories are interventions, not likelihood terms. Exclusion,
monitoring, and engagement can influence the next policy posterior only by
`do(policy) -> observed Y -> q(JOINT_POLICY_Y, theta_policy_to_Y) -> future
policy`. No history-name factor exists.

Denied contact is a typed, mode-specific relational outcome
`O_contact[k,t]`. It updates generic `theta_contact[k]` under the existing
mode-specific parameter scope. That posterior parameter enters future
expected consequences. A delivered token never directly increments access,
exile-like organization, or a policy score. Masking supplies no evidence.

Polarization is the signed interventional matrix

`D[i->j] = E_q[pi_j | do(pi_i=2)] - E_q[pi_j | do(pi_i=0)]`.

Each intervention fixes `pi_i`, removes its selection factor, and exactly
renormalizes the remaining joint-policy posterior. Independent structure has
zero `D`; opposed structure has reciprocal negative entries; allied structure
has reciprocal positive entries. Opposed and allied are never pooled.

## Mechanical pilot-to-floor rule

The rule is frozen before smoke and pilot:

1. Every nonzero causal-effect floor is exactly `0.50 *` its repaired-pilot
   point estimate. The same fraction applies to every nonzero effect.
2. Every recovery or coverage floor is exactly `0.90 *` its repaired-pilot
   point estimate. No value is rounded upward.
3. Calibration and proper-score ceilings equal the repaired-pilot point
   value plus the predeclared sampling allowance `0.03`.
4. Exact identities use `1e-10` and are never pilot-fitted.
5. Equivalence uses the predeclared absolute ROPE `[-0.01, 0.01]`; its entire
   95% interval must lie inside the ROPE.
6. A nonzero effect is attainable only if its paired pilot 95% interval has
   the declared sign. A failing sign stops the stage; no floor is authored.
