# V3.3 PRUNE public contract

Status: prospective, frozen before the attainability pilot.

## Scientific claim

Unburdening is ordinary posterior movement away from the same `M1_G`, `G_W`,
`G_A`, and `G_Y` edge-existence spikes established by V3.1 GROW. V3.3 adds no
burden variable, reduction operation, deletion command, or revised-outcome
assignment. The exact 128-program V3.1 graph posterior runs on context-indexed
typed evidence.

Context 0 retains the historical graph and its learned parameter rows. Context
1 receives corrective, imaginal, neutral, and return evidence through the same
interface. A mode may remain strongly supported while its current-context
identity-conditioned edges lose support. Historical edges need not disappear.

## Typed evidence and do-over

Each observation may type mode, root, world, policy proposal, action, and
outcome values. Missing values contribute no factor. `episode_kind` is custody
metadata and never enters a likelihood. Relabeling an otherwise identical
episode as imaginal or ordinary must leave every posterior probability exactly
unchanged. An imaginal do-over is therefore an ordinary joint typed episode; it
cannot call or author reduction.

The protocol schedules a timely do-over at the first slice after the observed
root-revision event: the first configural corrective observation with mode
`M1=1` and root `G=0`, contradicting the historical `M1_G` relation. The
premature arm begins before that event. Its paired no-do arm receives fully
masked, candidate-common observations at the identical event-indexed
opportunity. If no root-revision event is observed, neither arm receives a
timely opportunity. This scheduling is public protocol structure, not a
likelihood input.

A fully neutral observation has every scientific channel missing and contributes
Bayes factor one between every pair of structures. Evidence in one context
cannot change the other context's posterior or parameter rows. These
neutrality/dormancy identities are permanent Gate-1 obligations.

## Pure readouts

Current burden-edge mass is the maximum posterior existence probability among
`M1_G`, `G_W`, `G_A`, and `G_Y`. The absent-versus-present Bayes factor compares
posterior odds for all four edges absent against all four present, divided by
their prior odds.

Material reduction is true only when:

1. the mode posterior exceeds the frozen retention threshold;
2. current burden-edge mass is below the frozen low threshold;
3. absent-versus-present Bayes factor exceeds the frozen floor;
4. all conditions survive the frozen number of consecutive observations;
5. a candidate-common neutral observation changes no structure probability
   beyond `1e-10`; and
6. the result survives the later-stress segment in worlds where reduction is
   generatively correct.

The readout does not mutate the posterior. A separate historical query reports
the probability of the old graph and its parameter rows.

## Public API

`ref.v33` publishes `ReductionConfig`, `ReductionSlice`, `ReductionWorld`,
`generate_world`, `generate_recovery_world`, `score_world`,
`append_neutral_observation`, `relabel_episode`,
`burden_absent_present_bf`, `material_reduction_readout`, and
`first_material_time`. `root_revision_event` is the pure public scheduling
readout defined above. All generation/scoring helpers require an active
serializing trace sink. Every generator accepts `released_block`.
