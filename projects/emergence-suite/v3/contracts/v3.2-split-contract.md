# V3.2 SPLIT public contract

Status: prospective public contract, frozen before criterion-world execution.

## Scientific claim

V3.2 asks whether redescription can emerge as posterior movement over generic
parameter-scope and temporal-dynamics productions. It does not add a
redescription operation. A witnessing-style stream is sustained corrective
evidence held in a context; it may favor context-specific scope through ordinary
Bayesian evidence.

## Public grammar extension

The bounded V3 grammar exposes three external context slots. A structure chooses
an active-context count in `{1,2,3}` and, independently for each of two typed
parameter blocks (`cue_emission`, `outcome_emission`), one scope and one dynamics
production:

- scope: `shared_global`, `cue_specific`, or `context_specific`;
- dynamics: `static`, `discrete_recurrent_context`,
  `ordered_random_walk`, or `one_way_change`.

Thus `3 × (3 × 4)^2 = 432` programs compete by exact evidence under one
code-length prior. The blocks may receive different temporal parents, so a
drift-plus-recurrent world requires no new candidate family.

All categorical and Bernoulli likelihoods are normalized. Missing typed
observations contribute exactly zero log Bayes factor. A deleted slot's typed
channel is candidate-common masked. Lesioned posteriors must equal the full
posterior conditioned on the restricted structure prior within `1e-10`.

Before a second context is observed, context-specific scope is exactly
observationally equivalent to shared scope: slot 0 uses the shared reference
likelihood, and dormant context parameter blocks remain at their prior. Scope
can therefore be identified only by realized cross-context contrast. This
single-regime Bayes-factor-one identity is a permanent Gate-1 proof.

## Pure readouts

The familiar labels are summaries, not latent values:

- static: shared scope plus static dynamics;
- cue-local: cue-specific scope plus static dynamics;
- recurrent-context: context-specific scope plus recurrent dynamics;
- drift: ordered-random-walk dynamics;
- one-way change: one-way-change dynamics.

Raw redescription means context-specific scope has the largest posterior mass.
Material redescription additionally requires posterior context-scope mass at
least the frozen threshold, context-scope Bayes factor at least the frozen
threshold, and posterior mass for at least two active contexts at least the
frozen threshold. Selective redescription is material redescription plus
recurrent-dynamics mass above the same threshold. These V2.4-derived
distinctions are reported diagnostics only.

Historical prediction is a query of the posterior parameter store at a named
context and cue. It never deletes or overwrites another context. Present-context
transfer is the root revision carried through posterior context scope and the
cue-root association. Fixing `G` or setting that association to zero makes this
readout exactly zero.

## Public API

`ref.v32` publishes `TemporalStructure`, `TemporalHyperparameters`,
`generate_world`, `score_world`, `region_probabilities`,
`redescription_readouts`, `historical_prediction`, and
`present_context_transfer`. Every generator accepts `released_block`; omission
authorizes only the declared development block.

Worlds may carry no analysis label into inference. “Split,” “redescribed,”
“then,” “now,” and family names are rejected if presented as analysis labels.
Scientific state consists only of posterior/model-evidence stores and pure
readouts.

## Gate obligations

Gate 1 proves normalization, the 432-program prior sum, generator/scorer log
probability identity, independent enumeration parity, factor recombination,
scope and dynamics compilation, mixed-production coexistence, masked-channel
neutrality, restricted-prior consistency, readout purity, label exclusion, and
seed custody.

Gate 2 generates from every named posterior region using the scorer's own prior
and likelihood, and scores recovery, calibration, coverage, and exact log
probability using pilot-frozen floors.

Gate 3 tests all required open results, including witnessing evidence, a mixed
world, recurrence, one-way selectivity, transfer controls, and historical
retention. Gates 4–5 test selective production deletions, cumulative regression,
and robustness.
