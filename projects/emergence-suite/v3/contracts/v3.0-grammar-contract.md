# V3.0 exact grammar kernel contract

Status: public freeze candidate. Vocabulary is apparatus-only.

V3.0 exposes one bounded grammar with three context slots, three binary mode
slots, eight optional edges, and two generic parameter blocks. Each block has
one scope in `{shared_global, cue_specific, context_specific, mode_specific}`
and one dynamics value in `{static, discrete_recurrent_context,
ordered_random_walk, one_way_change}`. Complete programs compete under the
single normalized prior `p(H) ∝ 2^-L(H)`.

The licensed optional edges are `M1_G`, `M2_G`, `M3_G`, `G_W`, `G_A`, `G_Y`,
`W_Y`, and `doA_Y`. Edge absence is a spike at exact zero dependency. Actions
are interventions; their selection probability is never part of evidence.
All categorical rows are normalized and use the reusable symmetric
conjugate-prior family with concentration 0.5.

The primary fixture contains 786,432 complete programs. The production scorer
integrates every field support exactly using decomposable local scores. A
separately authored reduced oracle explicitly sums the joint Cartesian
product.

Mutable scientific state is limited to latent, parameter, and structure
posteriors and model evidence. Any clinical classification is a pure readout.
`grow`, `split`, and `prune` describe posterior movement only. They are not
public operations and no protocol may author their conclusions.

Public entry points are `generate_world`, `score_world`, `field_prior`,
`local_log_scores`, `compile_scope`, and `transition_matrix`. Every generation
entry point accepts an optional evaluator `released_block`; without one it is
restricted to the V3.0 development allocation.
