# T-CAP1 Census-3 grid and panel-selection freeze

This public, non-criterial census retains all 324 original cells unchanged. It adds coupling strengths `8.0` and `10.0`, yielding 486 cells in total. The frozen allocation equation already uses `coupling_strength` as its only posterior-coupling coefficient; it has no separate `beta_Phi`, so no beta extension is made.

The four descriptive classes are `null`, `weak`, `material_metastability`, and `pathological_nonqualifying`. A panel entry is always the first cell in the committed lexicographic parameter order. It is never the cell with the largest observed effect.

The world-level metastability fingerprint requires all eight round-30 properties: a cue response of at least `0.10`; transparent oracle-relative post-withdrawal area above the coupling-zero q95 reference; positive coupling necessity; positive transparent-versus-represented area on the same stream; eventual recovery; no delivered post-withdrawal congruent token; no continuing danger with final oracle probability at most `0.50`; and oracle calibration reported separately for continuing-danger worlds.

`epsilon` and `k` are selected mechanically from the public census. Candidate epsilon values are `0.05, 0.10, 0.20, 0.30, 0.50`; candidate run lengths are `4, 3, 2`. The first pair in epsilon-ascending, listed-k order attaining at least 80% recovery in safe coupling-zero original-grid worlds is used. If none qualifies, material metastability is unattainable under this definition. The post-withdrawal area threshold is the q95 of the same coupling-zero safe original-grid reference.

Raw hysteresis and historical `H_excess` remain descriptive. Neither is used to classify Census-3.
