# V3.0 decisions

1. The V3.0 publication fixture uses two generic parameter blocks:
   `cue_emission` and `outcome_emission`. This is the smallest fixture that can
   demonstrate coexisting scope and dynamics productions without introducing a
   named scientific family.
2. Active slots are represented as bounded counts with dormant higher-index
   slots. Slot activation remains a posterior coordinate; no runtime object is
   created.
3. The complete 786,432-program posterior is represented by exact field
   factors because both the frozen code prior and V3.0 diagnostic likelihood
   decompose. The reduced independent oracle explicitly enumerates its joint
   Cartesian product.
4. The causal-action composition assay is one same-definition paired assay
   reported as absent and present arms.
5. Gate 5 stopped on the first blocking failure. The apparent parity-helper
   software error was documented but not repaired without adjudication.
