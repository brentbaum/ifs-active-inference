## A1 — dynamic partner

The partner is a two-state hidden Markov process: `L_t ∈ {0,1}`, one state
per slice. Its initial prior is uniform. The persistence parameter has the
exact support `{0.80, 0.90, 0.97}` with uniform prior mass. For a value
`rho`, `p(L_t=L_{t-1})=rho`. Partner observations use the frozen typed
`remaining`-channel emission. Contact observations use the frozen contact
factor. Exact forward inference jointly marginalizes `rho`, `L_t`, and the
existing contact-response parameter. This factor replaces only the static
partner-trait mixture in the V3 adapter; it has no edge to modes or context.

## A2 — exogenous danger

`D_t ∈ {0,1}` is one exogenous binary world-state bit per slice. Its prior is
uniform (`1:1`) and stratum-agnostic. It is not a protocol label. `D_t=0`
uses the frozen mode-conditioned identity and outcome predictions. `D_t=1`
uses the same frozen atomic low-root/high-danger rows: identity-token
probability `0.14`, adverse-outcome probability `0.86`. The bit is exactly
marginalized and competes with mode-generated explanations. `do(action)`
remains an intervention and is never action-selection evidence. A2 has no
partner or context edge.
