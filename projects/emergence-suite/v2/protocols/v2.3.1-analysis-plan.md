# V2.3.1 frozen analysis plan

Frozen before running V2.3.1 diagnosis or repair protocols: 2026-07-27.

This plan treats the committed C-V23 failure as immutable evidence. C-V23b
remains sealed and is not used or inferred. All development seeds are below
800000. Every effect is reported with a 95% interval, and every failed
development threshold is retained.

## Diagnosis before repair

The diagnosis uses the frozen V2.3 strain on 512 open worlds, seeds
63000–63511. A balanced deterministic design varies:

- chronic regularity: periodic, jittered, Bernoulli, and clustered;
- run length: 16, 32, 64, and 80 slices;
- acute timing: first, middle, or final third;
- acute count: zero, one, or three;
- low-controllability prevalence: 0, .25, .50, .75, or 1 across event
  contexts.

The action pattern alternates independently of these dimensions. Event
prevalence is matched as closely as integer schedules permit. Event contexts
have collapsed broadcast; safe contexts have integrated broadcast.

The theory-variable readouts are:

1. evidence for uncontrollability: final posterior log odds for `C=low`
   minus its initial log odds;
2. cumulative overwhelm precision: the sum, over overwhelming slices, of the
   realized event-observation log likelihood ratio relative to the
   low-precision likelihood.

The surface readouts are regularity, run length, acute timing, and acute
count. Report calibration curves against both theory variables, grouped
surface effects, theory-only and surface-only linear cross-validated R², and
the incremental R² of surface features after theory variables. Report acute
step size against pre-acute persistent probability, timing, and precision
evidence.

Classification rule:

- **representational** if run length/timing/regularity add at least `.10`
  cross-validated R² after theory variables or if a surface group changes
  mean formation by at least `.20` at matched theory-variable bins;
- **parametric** if the theory variables dominate and failure is removed by
  prior/precision placement without changing the candidate family.

The acute path is representational if a static-prior boundary permits any
single-slice posterior change above the frozen V2.3 p99 bound
`.294529387`; otherwise it is parametric.

## Repair acceptance

The repair may change only the V2.3 stage-local parameter block and
transient/persistent family. It may not inspect schedule regularity, length,
timing, event count, or any derived schedule statistic. No posterior
threshold or write rule is permitted.

The 512 diagnosis worlds become an open generalization assay. On the repaired
strain:

- theory-variable calibration must be monotone in both dimensions;
- surface incremental cross-validated R² after theory variables must be
  `<= .05`;
- no slice in the expanded open battery may exceed `.294529387`;
- the new empirical p99 and maximum single-slice changes are both published;
- high-uncontrollability/high-overwhelm worlds must exceed their matched
  low-uncontrollability worlds in mean final persistent probability by `.20`,
  with a paired 95% interval excluding zero.

Existing V2.3 gate thresholds remain unchanged. The varied diagnosis assay is
added to gates 3 and 5 rather than replacing any original assay.

## Gates 1–5

1. Reprove all V2.3 semantic routes and independently enumerate the repaired
   finite comparison. Prove the structure transition and a global
   single-slice change bound without using observed schedule statistics.
2. Repeat structure, controllability, broadcast, and policy-parameter
   recovery with the original thresholds, plus calibration over the varied
   schedule assay.
3. Repeat all original open assays and the new varied generalization assay.
4. Lesion controllability inference, repaired formation coupling/dynamics,
   and reflexive broadcast separately. The predicted effects must disappear
   while inherited stages survive.
5. Repeat determinism, joint reliability perturbations, structure-prior
   sensitivity, the full local neighborhood, and every V2.0, V2.1, and
   V2.2.1 gate.
