# V2.0 frozen analysis plan

Frozen before execution: 2026-07-27.

- Gate 1: maximum engine/oracle absolute error across chain, fork, collider,
  and temporal queries must be `< 1e-10`.
- Gate 2: state accuracy `>= .75`, state Brier `<= .20`, state ECE `<= .12`;
  parameter posterior-mean absolute error `<= .08`, 95% interval coverage
  `>= .85`.
- Gate 3: engine and analytic nested-model log Bayes factor differ `< 1e-10`;
  the flexible model's integrated evidence must include its Occam cost.
- Gate 4: all 64 seeds 1200–1263 run, paired arms use identical component
  draws, and every factor deletion/mutation changes its targeted posterior by
  `> 1e-3`.
- Gate 5: the one-posterior audit passes after every protocol.

Effects use paired mean differences. Report 95% percentile bootstrap intervals
with 2,000 deterministic resamples. All failures are serialized verbatim.
