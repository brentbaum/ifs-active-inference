# V2.8 frozen analysis plan

## Status and custody

This is a composition-only final stage. The pilot blocks in the parameter
file are barred after attainability. Gate blocks and all four sealed escrows
are disjoint. No scientific failure in a comparator or genome is tuned away.

## Gate 1

At least thirty proofs cover reduced-fixture parity for every inherited
primitive, one-posterior custody, absence of duplicate scientific state,
absence of assay/stage labels from inference inputs, generic grammar
construction, exact 1/2/3-protector enumeration, full evidence/parameter
decomposition, read-only historical/current queries, direct-write audits,
independent reduced-fixture enumeration, input immutability, all finite bounds,
both constitutions, released-block threading, negative-fact aggregation, and
sealed custody.

## Gate 2

The fixed block `1700000:1749999` is processed once. Qualification is
prospectively fixed: P is the unique posterior argmax with probability at
least `.60` for the three burden strata; D is the unique argmax with
probability at least `.60` for real danger; maximum candidate mass must remain
below `1 - 1e-12`. The first 120 qualifying states per stratum are retained
only after the full block is processed. Reports include all eligibility rates,
calibration, false-P labeling of D, serialized hashes, and bitwise clone
checks.

## Gate 3

Use 480 fresh same-seed paired worlds, 120 per stratum, from the assigned
block. Run the full protocol and all ten comparators. Criteria, directions,
ROPEs, exact identities, and temporal ordering are exactly Section 9.5.
Whole-world bootstrap intervals use paired worlds.

## Gate 4

The thirteen Section-9 routes are lesioned one at a time on same-seed paired
fixtures. Each row declares target outcomes and inherited survivors before
execution. The complete matrix is published as CSV.

## Gate 5

Run the cumulative fast suite, both constitutions, inherited manifest-chain
verification, all grammar compositions, and the 128 preregistered genomes
with 24 worlds each. A genome is a seven-bit selection among already-frozen
protocol/world settings; it is not an inherited parameter mutation. All
3,072 profiles are published without selection. The final pre-seal linter
checks only constructibility and schemas for the four public challenge
shapes.

Reports separate scientific, semantic, distributional-stress, and custody
classes.
