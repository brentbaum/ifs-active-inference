## Population and nuisance design

The open formation population contains 960 worlds, seeds `742000:742959`.
A deterministic balanced design crosses or balances:

- cumulative overwhelm precision: five quantile levels;
- inferred uncontrollability evidence: five quantile levels;
- reflexive integration: collapsed, intermittently restored, integrated;
- real danger: absent or present;
- danger prevalence: `.10`, `.30`, `.50`;
- initial persistent-structure prior: `.15`, `.30`, `.45`.

Schedule dimensions are nuisance variables:

- length: 48, 72, or 96 slices;
- chronic regularity: periodic, jittered, Bernoulli, or clustered;
- acute count: 0, 1, or 3;
- acute timing: early, middle, or late;
- ordering: chronic-first, acute-first, or interleaved.

Assignment uses balanced permutations independent of theory-variable levels.
Schedules compile only to public factors. No factor or inference function may
read length, regularity, count, timing, ordering, protocol name, seed, or an
analysis label.

Formation is persistent-model selection at log evidence margin `>= 1 nat`.
Calibration additionally uses the continuous posterior and evidence margin;
the binary selection is not the sole endpoint.

## Prior-predictive computation and frozen SESOIs

This computation was completed before sealed bundles exist. It is a design
calculation, not a V2.3.2 mechanism implementation.

Using RNG seed `732320`, 2,000 design-prior draws were evaluated on 4,096
balanced theory-variable profiles per draw. Let `sigmoid` be `s`. The
design-only predictor was:

`p = s(beta0 + betaO*O + betaU*U + betaC*C`

`      + betaOU*O*U + betaD*D + betaPrev*(prevalence-.30)`

`      + logit(structure_prior) + .85 + nuisance)`.

The design priors were:

- `beta0 ~ Normal(-1.35,.20)`;
- `betaO ~ |Normal(.90,.15)|`;
- `betaU ~ |Normal(.85,.15)|`;
- `betaC ~ |Normal(.45,.10)|`;
- `betaOU ~ |Normal(.70,.12)|`;
- `betaD ~ |Normal(.70,.15)|`;
- `betaPrev ~ |Normal(.30,.08)|`;
- `nuisance ~ Normal(0,.12)`;
- calibration temperature `T ~ Uniform(.85,1.15)`, with reported
  `q=s(logit(p)/T)`.

Expected accuracy is `mean(max(p,1-p))`; Brier is
`mean[p(1-q)^2+(1-p)q^2]`; ECE uses ten equal-width q bins. Control and
monotonicity contrasts are calculated on matched canonical profiles. For
continuity, 1,000 carried probabilities per draw receive a bounded
single-slice log-evidence increment `Uniform(-.45,.45)`.

The resulting attainable 5th–95th percentile ranges and frozen criteria are:

| Profile metric | Prior-predictive 5–95% range | Frozen criterion / SESOI |
|---|---:|---:|
| Expected structure accuracy | `.689–.721` | `>= .68` |
| Structure Brier | `.183–.201` | `<= .21` |
| Population ECE | `.001–.0218` | `<= .04`, including finite-sample allowance |
| Matched uncontrollability/control contrast | `.185–.283` | SESOI `>= .12`, paired CI lower bound `>0` |
| Minimum canonical overwhelm monotonic contrast | `.124–.250` | SESOI `>= .08`, paired CI lower bound `>0` |
| Benign-profile false selection | exactly `0` in the envelope | `<= .05` in every prior stratum |
| p99 single-slice change | `.103–.1075` | `<= .11` |
| maximum single-slice change | `.109–.1118` | `<= .12` |

For beneficial contrasts the SESOI is approximately two-thirds of the
attainable fifth percentile, rounded down to `.01`; this preserves power
without demanding the design-prior center. Error ceilings round the
attainable 95th percentile upward and add only the stated calibration or
finite-world allowance. These numbers are immutable for open and sealed
scoring.

4. matched overwhelm-precision and collapsed-integration effects;

monotonicity has no sign reversal, and schedule-surface incremental CV R² is
`<= .05`. A good aggregate score cannot hide a failed stratum.

  rescinded Gate-2/3 baseline;

The binding anti-authoring checklist is:

- no avoidance→persistence factor
- no K→root update
- no outcome-label branch
- irrelevant-action safety reduces threat
- masked outcomes create no evidence
- relief never touches threat
- all counterfactual readouts posterior-derived

Any failed item is an architecture failure, independent of numerical scores.
