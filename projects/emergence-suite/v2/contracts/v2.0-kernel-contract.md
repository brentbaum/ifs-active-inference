# V2.0 kernel contract

Version: V2.0-freeze-candidate-1

## Public vocabulary

- Variable: `name`, `cardinality >= 2`, `kind` (`latent`, `observation`,
  `policy`, `parameter`, `structure`), optional integer `time`.
- Factor: ordered `variables`, nonnegative finite `values`, and one declared
  template name. Kernel template names are `categorical_prior`,
  `conditional_categorical`, `conjugate_dirichlet`,
  `finite_model_evidence`, and `product`.
- Protocol: `stage`, `assay`, development `seed`, `model`, observations, query,
  and named thresholds. Seeds must be integers in `[0, 799999]`.
- Observation kinds share the factor likelihood interface. A kind changes a
  declared likelihood table, never the inference API.
- Protocol state has exactly posterior, parameter-posterior, and model-evidence
  stores plus immutable non-scientific metadata.

## Readouts

Posterior probabilities, calibration error, confusion matrices, log evidence,
Bayes factors, and effects/intervals are pure functions of the three stores.
Readouts are never written back into model state.

## Exactness

The reference engine uses sum-product variable elimination. The public checker
uses direct Cartesian-product enumeration and shares no engine intermediates.
