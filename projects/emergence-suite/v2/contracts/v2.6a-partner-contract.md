# V2.6a latent-partner and co-regulation contract

## Public structure

`L_t` is the sole latent partner process and has four values:
`reliable_contingent`, `soothing_noncontingent`, `intrusive`, and
`unstable`.  It is a declared Markov process.  Conditional on `L_t`, the
four binary relational channels—regulation signal, remaining behavior,
respect behavior, and trust-relevant outcome—are independent normalized
emissions. Missing channels contribute likelihood one.

Exact filtering and smoothing produce the one partner posterior, the
pairwise switch posterior, and the local relational-precision posterior
readout.  When broadcast is enabled, expected relational precision informs
global precision.  When broadcast is disabled, local partner inference is
bitwise unchanged and the global precision remains at its declared base.

Root evidence is a separate observation channel. Its likelihood is
precision-controlled, but `L_t`, partner labels, relational observations,
and the `co_regulated` readout never enter the root likelihood as evidence.
Consequently relational-only slices have root Bayes factor exactly one.
The same root token is used across factorial arms. No intervention or
readout writes `G`.

`co_regulated`, root movement, transfer, global depth, local arousal, switch
probability, and future precision forecast are pure posterior readouts.
They are never inputs to inference. Generated worlds and scoring entry
points accept an explicit `released_block`; the default is the declared
Epoch-B development block.

## Public API

- `generate_recovery_world(seed, length=None, released_block=None)` samples
  its initial state and every transition from the frozen scorer process.
- `generate_factorial_world(seed, regulation_present, root_evidence_present, released_block=None)`
- `generate_control_world(seed, partner_family, released_block=None)`
- `generate_switch_world(seed, released_block=None)`
- `score(observations, broadcast=True, fixed_g=None, ...)`; the four
  default-true lesion switches control partner-to-precision, root evidence,
  transition learning, and the shared partner latent. `broadcast=False` is
  the relational-to-global lesion. Defaults reproduce the unlesioned model.
- `finite_information_bounds()`

The scientific state contains only normalized partner/root posteriors,
positive parameter posteriors, model evidence, and immutable metadata.

## Gate obligations

Gate 1 publishes sixteen proofs: shared latent generation; emission,
transition, and prior normalization; genuine local-precision weighting;
broadcast-local invariance; absence of labels from root inference;
regulation-only root BF unity; root-token arm identity; intervention/evidence
separation; switch-posterior identity; independent enumeration parity;
oracle input immutability; readout purity; the one-posterior audit; permanent
constitution and manifest-chain composition; and finite-information bounds.

Gates 2 and 3 use the exact thresholds and seed blocks in Section 5 of the
remaining-stages specification. No sealed escrow is part of this contract.
