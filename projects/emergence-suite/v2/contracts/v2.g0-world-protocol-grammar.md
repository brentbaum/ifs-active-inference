# V2.G0 compositional world and protocol grammar contract

**Status:** public apparatus contract  
**Stage:** R0 / V2.G0  
**Claim class:** apparatus only; no psychological or clinical claim  
**Implementation:** `ref/world_ir.py`, `ref/protocol_ir.py`  
**Independent oracle:** `ref/world_ir_oracle.py`

## Scientific-state boundary

V2.G0 generates typed truth and observation traces. It does not add, mutate,
clamp, or label scientific posteriors. Protocol names, world-family names,
constructor metadata, and hashes are custody fields and are excluded from the
`inference_input` payload.

All V2.0–V2.4.4 and V2.5a-in-flight files are inherited byte-for-byte. V2.G0
is a new module and does not backport constructors into a frozen stage.

## Typed world document

A world document is a mapping with:

```python
{
    "stage_version": "V2.G0",
    "name": "<public identifier>",
    "processes": [<typed process>, ...],
}
```

Every process declares a unique `name`, a `kind`, a nonempty finite `scope`,
and kind-specific parameters. Product composition is the default and requires
disjoint scopes. A scope is a tuple of cue IDs, latent-variable IDs,
observation IDs, or nuisance IDs. Scope membership is public in every trace.

### Process primitives

| Kind | Declaration and exact semantics |
|---|---|
| `static` | `value`, or finite `values` plus normalized `probabilities`; one draw is held for `length` events. |
| `iid` | normalized finite `values`/`probabilities`, or a bounded continuous uniform density declared by `distribution="uniform"` and finite `bounds=[low, high]`. |
| `markov` | finite `states`, normalized `initial`, and a normalized row for each state in `transition`. |
| `ordered_drift` | Markov semantics plus a declared sorted state grid. The transition template is explicit and normalized. |
| `change_point` | `before`, `after`, a normalized finite `onset_probabilities` mapping over integer onset indices and optional `no_change`, plus `onset_window` and `allow_no_change`. Conditioning renormalizes exactly. |
| `recurrent_context` | finite Markov semantics with an optional exact path restriction. |
| `action_contingent` | finite Markov semantics with a declared intervention sequence and one normalized transition matrix per action. Action-selection probability is absent. |
| `masked_observation` | candidate-common iid availability indicators with declared `availability`; the protocol maps unavailable values to `None`. |
| `joint_episode` | normalized categorical draws over records spanning declared channels. |
| `partner_process` | one finite latent Markov path with normalized channel emissions conditional on the same latent state. |
| `joint_policy_outcome` | one normalized outcome distribution for every declared finite joint-policy vector. |

### Composition operations

- **Product:** list processes with disjoint scopes in one world.
- **Subset assignment:** put exactly the intended cue/latent IDs in a process
  `scope`; unlisted IDs are outside that process.
- **Shared latent:** `kind="shared_latent"` declares one `latent` process and
  an explicit finite target list. The identical sampled path is published for
  every target.
- **Mixture:** `kind="mixture"` declares finite `components` with a common
  scope and normalized `weights`. The selected component is an explicit trace
  field and contributes its mixture mass to the world probability.
- **Candidate-common nuisance:** declare the nuisance scope and
  `candidate_common=True`; `masked_observation` is the public availability
  instance.
- **Support restriction:** attach `restriction` to a finite path process.
  The compiler publishes the exact conditional normalizer.
- **Generic bridge:** `run_bridge(initial_state, world_spec, protocol_spec,
  rng)` compiles and runs any declared family. No family or context-split
  branch exists in the bridge.

## Exact path restrictions

The public restriction keys are:

```python
{
    "onset_window": [first_inclusive, last_inclusive],
    "allow_no_change": False,
    "at_least_one_switch": True,
    "old_context_recurrence": True,
    "minimum_visits": {"state": count},
}
```

For a finite unconditioned path mass \(p(x_{0:T-1})\), the compiler enumerates
the declared finite support, retains exactly the paths satisfying the
restriction \(R\), and publishes

\[
Z_R=\sum_x p(x)\mathbf{1}[R(x)].
\]

The sampler draws once from the normalized retained support
\(p(x\mid R)=p(x)\mathbf{1}[R(x)]/Z_R\). There is no seed rejection, retry
loop, or hidden budget. `public_normalizer(process_spec)` returns \(Z_R\).
The independently authored Cartesian oracle separately reconstructs the same
conditional mass.

## Protocol document

```python
{
    "stage_version": "V2.G0",
    "name": "<custody-only identifier>",
    "actions": [<do intervention>, ...],
    "observation_channels": [
        {
            "name": "<channel>",
            "source_process": "<process>",
            "path": [<optional nested keys>],
            "masked_by": "<optional availability process>",
        }
    ],
}
```

`run_protocol` samples the world, applies candidate-common availability, and
publishes observations and interventions. The action vector is conditioned on
as `do(action)`; no action-selection likelihood is generated.

## Public API

```python
compile_world(world_spec) -> CompiledWorld
sample_world(compiled_world, seed) -> WorldTrace
log_prob_world(compiled_world, truth_trace) -> float
compile_protocol(protocol_spec) -> CompiledProtocol
run_protocol(initial_state, compiled_world, compiled_protocol, seed) -> ScientificTrace
dry_run_schema(world_spec, protocol_spec, seed) -> SchemaAudit
independent_world_log_prob(world_spec, truth_trace) -> float
run_bridge(initial_state, world_spec, protocol_spec, rng) -> ScientificTrace
```

Every completed trace contains both spec hashes, process scopes, truth,
observations, interventions, component RNG keys, exact world log probability,
and an output-schema hash. A pre-protocol `WorldTrace` uses
`protocol_spec_hash=None`, empty observations, and empty interventions.

## RNG and custody

Every stochastic draw is keyed by:

```text
("V2.G0", world_seed, component_namespace, time_or_event_index)
```

The public sampler accepts only `1000000:1009999`. It explicitly refuses the
diagnosis-reserved `1010000:1019999` and sealed C-V2G0 escrow
`2000000:2000499`. This implementation does not read or touch escrow.

The four-layer dry-run returns only construction success, support, lengths,
schema/field presence, deterministic hashes, and the explicit flag
`scientific_scores_inspected=False`.
