# V2.3.4 counterfactual action-attribution contract

## Scientific state

The exact scientific posterior ranges over danger rate `theta` and two
context-indexed efficacy magnitudes `(eta_0, eta_1)`. The unique
`(0,0)` configuration is `H_E=irrelevant` and carries an exact spike.
Every other configuration belongs to the causal slab. No epsilon substitute
for zero is permitted.

At each slice, `D` is catastrophe without protection, `A` is an intervention,
`P` is prevention success, `Y = D[1-I(A=protect)P]`, and `M` determines
whether `Y` is observed. The single normalized likelihood marginalizes
`D,P,Y`. Optional near-miss and efficacy observations are ordinary
diagnostic evidence. There is no probability or likelihood for action
selection.

Relief is candidate-common policy feedback. It updates only the policy
parameter posterior and never danger, efficacy existence, efficacy
magnitude, or formation. `K=I(D=1,A=protect,P=1,Y=0)` is a pure posterior
readout and has no authored feedback path.

## Public API

- `generate_world(seed, identifiable, length=96, released_block=None, ...)`
- `generate_controlled_world(seed, scenario, released_block=None)`
- `score(episodes, initial_prior=None, lesions=())`
- `slice_likelihood(episode)`
- `finite_information_bound()`

Every generation entry point threads `released_block`. Oracles copy all prior
inputs. Comparisons use the declared tolerance.

## Claims

The licensed distinction is low danger versus danger successfully prevented
by action. Mere safety never positively strengthens threat. Positive
strengthening requires separately diagnostic near-miss or efficacy evidence.
Actions are `do(A)` conditions, never observations.
