# V2.1 recursive precision contract extension

Version: V2.1-freeze-candidate-1; inherits V2.0 unchanged.

- `lambda[channel,time]` is a finite local precision latent.
- New likelihood templates are `precision_modulated_categorical` and
  `precision_modulated_bounded_gaussian`; both use the one public observation
  likelihood constructor.
- A categorical likelihood is sharpened by exponentiating each positive base
  row by the precision support value and renormalizing that row.
- A bounded-Gaussian likelihood uses variance `exp(-lambda)`.
- `Phi[time]` is a three-state hyper-latent over the lambda collection.
- The optional broadcast factor connects current local precision to Phi. It is
  separately deletable and constructed so that, absent other global evidence,
  marginal local inference is unchanged.
- The return factor connects Phi to future local precision.
- Integrated-calibrated regime is structurally `Phi=2`: channels share a
  calibrated high-precision prior and the return route is active. Depth is
  `P(Phi=2 | observations)`, not an average of stored values.
- Dominance is total-variation influence on a target posterior after deleting
  exactly one declared evidence factor.
