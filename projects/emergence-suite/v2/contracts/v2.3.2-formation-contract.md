# V2.3.2 formation re-foundation contract

Version: V2.3.2-formation-1.

This is the operative V2.3.2 formation contract under
`suite-v2-c1-restructure-plan.md`. It supersedes
`protocols/v2.3.2-F-analysis-plan.md` and the attribution-first ordering.
The committed attribution mechanism is shelved intact for the conditional
V2.3.4 rung; none of its factors, readouts, or Gate-2 results are used here.

## Static candidate family

`H_formation` is a static finite structural hypothesis over:

- `T`: transient event;
- `D`: persistent external danger, without identity-root recruitment;
- `P`: persistent identity bundle coordinated through the root.

The prior is charged once at sequence start. There is no Markov transition,
formation hazard, recovery hazard, onset clock, boolean formation write, or
post-inference increment. Posterior odds are the prior odds times normalized
prequential likelihood ratios and remain reversible under later evidence.

T/D/P is preregistered because adaptive real danger should favor D rather
than count as identity formation. A literal onset time is unnecessary: the
scientific question is which static model best predicts the developmental
sequence, and posterior model probability already changes continuously.

## Normalized predictive factors

Candidates differ only through normalized predictions corresponding to:

- `p(S | G,H)` — identity-root/self observation;
- `p(E | G,H)` — event observation;
- `p(Y | G,A,W,H)` — action-dependent outcome;
- `p(W' | W,A,C,H)` — action/outcome transition and controllability;
- `p(X | E,R,H)` — contextual localization;
- `p(O_cfg | S,Y,X,H)` — a normalized joint configural observation.

The exact reference compiles these into one normalized categorical
distribution over the shared `(S,Y,X)` support for each candidate and public
theory configuration. This is merely variable elimination over the listed
factors, not a new scientific route.

No event makes every channel candidate-identical. A masked slice contributes
likelihood one under every candidate. Collapsed broadcast makes `X=missing`
candidate-independent. Overwhelm changes the precision of the normalized
configural distribution. Low control changes action–outcome predictions.
Nothing directly increments P.

## Public API and evidence decomposition

`slice_distribution(candidate, configuration, lesions)` returns the
normalized predictive row. `score_slice(prior, observation, configuration)`
returns the posterior, total evidence, and published candidate log
contributions. `score_history` multiplies these contributions sequentially.

The public decomposition reports self, outcome/control, localization, and
configural-normalization terms. Their sum must reproduce every candidate
log likelihood and every pairwise log BF to `1e-10`.

`independent_history_sum` is a separately authored scalar summation path. It
may read public tables but shares no scorer or decomposition implementation.

## Permanent constitution

Every structural comparison obeys the nine retroactive invariants:
normalized common support; prior/complexity once; masked zero; absent zero;
identical-prediction zero; prequential recombination; included partitions;
declared no-evidence dynamics; and an independent implementation.

## Readouts and stores

Scientific state is restricted to posterior, parameter-posterior, and
evidence stores. Candidate selection, confusion matrices, Brier/ECE,
formation labels, BF decompositions, and schedule-invariance contrasts are
pure readouts. P selection uses the finite posterior/evidence margin only;
there is no mutable `formed` field.

## Lesions

1. `root_coupling`: P receives the same self prediction as D; P-specific
   evidence disappears while D remains.
2. `control_inference`: candidate action–outcome rows are equalized; the
   control contrast disappears.
3. `context_route`: localization is masked; the broadcast contrast
   disappears.
4. `event_precision`: overwhelm uses ordinary precision; sharpening
   disappears.
5. `structure_comparison`: all candidates receive the same normalized
   predictive row; every BF disappears.

## Freeze obligations

The freeze contains the exact pre-schedule one-slice expected-log-BF sign
table, including no-event and masked zero rows and D/P-discriminating rows.
Schedule invariance under matched sufficient statistics is the primary
generalization estimand.
