# V2.2 decision log

- Root association is a learned conditional reliability; perceptual similarity
  is a separate cue-recognition likelihood and never enters the root factor.
- Direction is made identifiable by an asymmetric exogenous root prior. The
  shared and reversed candidates integrate the same-size reliability parameter,
  so comparison does not favor one by parameter count.
- “Identical corrective information” means the same `O0=1` likelihood in all
  seam regimes. Only the observed local monitor and presence of broadcast vary.
- Root admission is an ordinary `p(M0 | Phi,G)` CPT. No update gate or
  post-inference write exists.
- Mediation is tested by fixing G to its pre-correction posterior and deleting
  the cue-root factor. Untreated transfer must then be exactly zero.
- The broadcast-off condition is the first computational face of a self-like
  part: accurate local monitoring with reduced depth, root uptake, and transfer.
