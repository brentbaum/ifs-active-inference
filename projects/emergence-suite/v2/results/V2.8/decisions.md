# V2.8 decisions

- Chose composition-only orchestration. No V2.8 scientific factor, posterior,
  likelihood, prior, transition, or mutable state was introduced.
- Used T/D/P rather than a binary formed flag. Developmental qualification is
  a pure posterior readout.
- Increased the protocol's redescription information budget from the initial
  32-slice pilot to the frozen V2.4 primary 96-slice budget. The barred pilot
  showed 32 slices could not reliably resolve the inherited exact family
  comparison. This changes an observation budget, not a scientific parameter.
- Defined the 128 genomes as the complete seven-bit factorial over inherited
  history/protector, partner, broadcast, association, context, and reduction
  settings. Every genome is reported; none is selected.
- Used component-level frozen lesion paths in Gate 4. This avoids inventing a
  trajectory-level lesion mechanism and makes each survivor identity explicit.
- Retained a deterministic thread fallback because the sandbox denies process
  semaphore inspection. Task order, seeds, and scientific calls are identical.
