# Seed escrow and staged release convention

The private escrow is one canonical UTF-8/LF/final-newline TOML file with:

```toml
experiment_id = "experiment-51"
contract_id = "ifs-ai-experiment-51-contract"
contract_version = "1.0.1"
contract_commit = "<40 lowercase hex>"
rng_convention = "rng-51-v1"
generation = "os-csprng-256"

[[release_blocks]]
id = "<opaque id>"
class = "H | C | P | L"
purpose = "<opaque purpose id>"
count = 80
release_order = 1
master_seed_hex = "<64 lowercase hex>"
```

There is at least one block in each class 51-H, 51-C, 51-P, and 51-L. Each
256-bit master seed is independently generated by the operating-system CSPRNG.
Master seeds, expanded seeds, and purposes remain private until their scheduled
release.

For zero-based index `j`, the unsigned 64-bit run seed is the first eight bytes
of:

```text
SHA256(
  "ifs-ai-51-seed-v1" || NUL ||
  hexdecode(master_seed_hex) || NUL ||
  utf8(class) || NUL ||
  utf8(id) || NUL ||
  uint64be(j)
)
```

interpreted big-endian with the high bit cleared. Sol expands every block before
sealing and rejects any collision across the complete H/C/P/L escrow.

The release-block commitment is:

```text
SHA256(
  "ifs-ai-51-seed-block-v1" || NUL ||
  utf8(experiment_id) || NUL ||
  utf8(contract_id) || NUL ||
  utf8(contract_version) || NUL ||
  utf8(contract_commit) || NUL ||
  utf8(id) || NUL ||
  utf8(class) || NUL ||
  utf8(purpose) || NUL ||
  uint64be(count) || NUL ||
  uint64be(release_order) || NUL ||
  hexdecode(master_seed_hex)
)
```

The seal records each opaque block ID, class, count, release order, commitment,
the SHA-256 and byte count of the exact escrow TOML, and the contract commit.
The exact escrow file is retained; it is not regenerated. A release publishes
the corresponding table verbatim, allowing independent commitment and expansion
verification without revealing later blocks.

Allowed block count is `1...512`; total expanded seeds are at most `4096`.
Block IDs, purposes, and release orders are unique. Release orders are exactly
`1...N`, and blocks appear in that order in the escrow. Every class is present.
`scripts/contract/seed_escrow.jl` is the authoritative validator, collision
checker, commitment calculator, and public-manifest formatter.

The formatter requires the expected 40-hex public-contract commit as a command
argument and rejects a mismatch. Its public output includes that commit, escrow
hash/bytes, and each block's ID, class, count, release order, and commitment.
It never prints `purpose` or seed material.
