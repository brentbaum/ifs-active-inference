## V2.3.3 — evidence-shaping maintenance (normative summary)

**Question:** conditional on an already formed identity organization, can policy preserve it solely by changing which corrective observations become available? (The attribution question — "did the agent infer safety occurred because of avoidance" — remains V2.3.4.)

**Minimal structure:** potential outcome Y*_t ~ p(·|H,G,W,C); availability M_t ~ p(·|do(A_t),Z); O_t = Y*_t if observed else missing. A_t controls M_t only (not Y*_t in V2.3.3); do(A_t) is never H-evidence; missing contributes BF exactly zero; no efficacy/prevented-catastrophe/relief/attribution variables. The only new route: policy → availability → delivered evidence → H/G.

**Formed-world bank:** developmental histories through frozen V2.3.2, no assigned posteriors; three preregistered initial-strength strata (q0(P): 0.60–0.75 / 0.75–0.90 / 0.90–0.98 — no numerical saturation); per-seed serialized+hashed full state (q(T,D,P), root, cue and structural posteriors, precisions, action-outcome posteriors, candidate log evidence, provenance); every arm gets a **bitwise clone** (matched = exact within-seed identity). **Intention-to-simulate:** first eligible worlds from a fixed seed block; report all seeds, eligibility by stratum, exclusions with reasons, full-population and per-stratum results, and the maintenance effect as a continuous function of initial q(P); no generating until favorable.

**Six arms:** A response prevention (engage, full observation → safe evidence reduces P); B closed-loop censoring (endogenous avoidance censors → P erodes less because less evidence arrives); C yoked replay (B's exact mask/evidence stream replayed → trajectory identical to B); D avoidance with observed safety (avoid, full → same erosion as A); E sham avoidance (ritual action, full, candidate-common feedback → same as A); F real-danger controls (external danger favors D; identity-implicating danger may preserve P). Plus censoring-dose c ∈ {0, .25, .5, .75, 1} → graded retention curve.

**Readouts:** log-odds L^PT, L^PD; ΔL per arm; maintenance effect M^PT = ΔL_censor − ΔL_full (positive = censoring protected P); delivered/censored counts; realized avoidance; root revision; untreated-cue transfer; policy posterior. Evidence and log odds, not raw probability differences.

**Gate 1 (12 semantic proofs):** censored/absent → BF exactly 0; observed safe → frozen negative BF; action contributes no H-evidence; identical delivered evidence → identical trajectories regardless of action label; closed-loop ≡ yoked bitwise when streams identical; complete censoring preserves prior odds exactly; partial-censoring totals = sum of delivered per-slice BFs; reorder-invariance; independent oracle; V2.3.2 homotopy + analytic bound still valid; no code path action→H, mask→positive-P, selected_policy→root.

**Gate 2:** calibration within V2.3.2 bounds (or frozen degradation margin) across censoring levels; exact delivered/censored recovery from traces; no false P-strengthening under safe observed worlds; endogenous avoidance nondegenerate (0.20–0.80 open); bitwise clone verification; per-stratum minimum world counts; no criterion calibrated on the maintenance contrast.

**Gate 3 (≥120 paired worlds, stratum-balanced):** observed safety erodes (upper CI < 0 both contrasts); complete censoring |ΔL| ≤ 1e-10 (no strengthening); maintenance contrast CI > 0 both contrasts; yoked identity ≤ 1e-10; no action bonus (numerical identity where evidence literally identical); dose response monotone with the mechanistic identity (final evidence = exact sum of delivered contributions) primary over the statistical slope; T/D/P danger control (identity-irrelevant danger → D; generic adversity must not maintain P); C3 composition (observed evidence → more root revision/transfer than censoring; fixing G removes transfer, leaves maintenance contrast).

**Gate 4 lesions:** action→mask contingency; forced-open channel; action-label permutation (nothing scientific changes); masked→safe substitution (plateau becomes erosion); candidate-common outcome likelihood; root coupling; global broadcast; structure comparison — each with disappear/survive predictions; all earlier gates survive where unrelated.

**Gate 5 sweeps:** initial stratum, duration, safe-outcome reliability, censoring probability, action cost, policy temperature, adverse-outcome proportion, T/D/P priors, precision regimes, cue-root strengths; audits: one-posterior, independent recomputation, paired RNG, per-slice BF decomposition, joint neighborhood, no direct action/mask→H path, graded-update audit stratified by observation class.

**Gate 6 — two sealed blocks:** **C-V233-M-bank** (bank qualification on fresh developmental histories: does the frozen constructor yield sufficient moderate/strong P states without posterior assignment? maintenance seeds stay closed if it fails — no burning a maintenance challenge on a formation-starved population); **C-V233-M** (private variation of initial strength, censoring rate, reliability, action cost, schedule, labels, external vs identity-implicating danger, one context shift; nine sealed criteria: erosion, protection, no-strengthening-under-complete-censoring, yoked equivalence, no action bonus, graded dose, D/P discrimination, root/transfer follows delivered evidence, cumulative semantic gates). **No tail-percentile continuity criterion.**

**Execution sequence:** adjudication commit → revised graded-update constitution → public contract/analysis-plan/dummy → evaluator seals both blocks with escrow → implement open primitive → gates 1–2 → bank procedure freeze → gates 3–5 → evaluator verifies freeze → release bank seeds → if pass, release maintenance seeds → run once, retain everything → decide V2.3.4 timing.
