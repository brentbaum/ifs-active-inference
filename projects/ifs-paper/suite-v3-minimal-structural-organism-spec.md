# Suite v3 — the minimal structural organism

**Status:** Proposed compression lineage after Suite v2 completion  
**Date:** 2026-07-30  
**Implementation home:** `projects/emergence-suite/v3/`  
**Paper home:** `projects/ifs-paper/`  
**Relationship to Suite v2:** Suite v2 remains immutable as the expanded, mechanism-isolation reference. V3 is a new model-compression study, not a repair, replacement verdict, or retroactive reinterpretation of any V2 result.

---

## 0. Executive decision

Suite v2 deliberately separated formation, episode structure, burden reduction, action efficacy, temporal redescription, partner learning, and protector organization into independently testable structures. That strategy was useful for falsification and localization, but it produced multiple hand-carved hypothesis menus that answer variants of one question:

> Which dependencies exist, which context or mode scopes them, how strong are they, and which observations support retaining or removing them?

V3 replaces the separate menus with one bounded exact **context-indexed sparse-graph grammar**. The core structural productions are:

1. activate a dormant latent mode or context slot;
2. include or exclude a dependency edge;
3. scope a parameter globally, by cue, by context, or by mode;
4. choose a generic temporal process for a parameter block;
5. infer the same structure posterior as evidence accumulates.

“Grow,” “split,” and “prune” are names for posterior movement over this fixed grammar. They are not state-changing therapy operations and are never callable by a protocol.

The intended compression is:

```text
T/D/P formation menu
+ H_cfg / kappa episode menu
+ Z_W / Z_Pi / Z_Y reduction lattice
+ H_E / eta efficacy menu
+ five named temporal families
------------------------------------------------
= one posterior over a bounded structural grammar
```

The V3 paper claim, if earned, is:

> A burdened part is a recurrent latent mode in which identity has become coupled to predictions about world, action, and outcome under a particular context and precision regime. Formation increases support for that mode and those dependencies; protection changes the evidence they receive; witnessing revises identity while the mode remains represented; redescription makes dependencies context-specific; and unburdening removes their compulsory force without deleting the mode or its history.

# 1. What remains primitive

V3 does not attempt to derive everything. A quantity is primitive when it cannot be generated by a production in the grammar without changing the scientific question.

## 1.1 Primitive ontology

The minimum typed variables are:

- **external / temporal context** `C_t`;
- **latent internal modes** `M_{k,t}`, with a bounded number of dormant slots;
- **identity root** `G_t`;
- **world state** `W_t`;
- **intervention / policy** `A_t`;
- **outcome** `Y_t`;
- **partner state** `L_t`, introduced only in the relational stage;
- **recursive precision hierarchy** `Phi_t`, inherited from V2.1;
- typed observations over cue, bodily, relational, contextual, episodic, imaginal, and outcome channels.

The channel ontology is declared. The model cannot learn from raw tokens that one stream is an action and another is an interoceptive observation.

## 1.2 Primitive computational semantics

The following remain primitive:

- `do(action)` semantics: interventions are not observations;
- exact Bayesian state, parameter, and structure inference;
- policy selection from predicted outcomes and preferences;
- recursively coordinated precision;
- generic preferences and costs;
- one generic structural-complexity prior;
- generic conjugate parameter priors.

V3 does not claim to derive suffering aversion, effort cost, the value of information, or the distinction between self, world, action, and outcome.

## 1.3 Not primitive

The following may never be latent or mutable V3 scientific objects:

- `T`, `D`, or `P` as named candidate kinds;
- `formed`, `part`, `protector`, `exile`, `burden`, `unburdened`;
- `H_cfg` as a special episode ontology;
- `H_E` as a special efficacy ontology;
- `Z_W`, `Z_Pi`, and `Z_Y` as a second burden-only lattice;
- `global_downweight`, `cue_local`, `context_split`, `drift`, or `change_point` as psychological family labels inside inference;
- independent trust-state objects for outcome, co-protection, partner, and efficacy;
- topology labels such as independent, opposed, or coalition;
- `permission`, `access`, `polarized`, `witnessing`, or therapeutic-stage labels.

These may exist only as frozen analysis readouts over ordinary posteriors.

# 2. The V3 generative model

## 2.1 Bounded exact state space

Primary publication bounds:

```text
K_C = 3 external / temporal context slots
K_M = 3 internal mode slots
G_t, W_t, Y_t in {0,1}
A_t in {engage, protect, seek_support}
Phi_t uses the standing exact V2.1 local/global precision support
L_t in four finite partner states, introduced at V3.4
```

A dormant context or mode slot is represented inside the prior. “Birth” means posterior support moves from unused to used; no code creates an object after seeing an outcome.

Multiple `M_k` are binary features rather than one mutually exclusive categorical mode. This is required because polarization and coalition require simultaneous activation.

## 2.2 Fixed supergraph and optional productions

The exact supergraph licenses a small set of optional dependencies. The first core license is:

```text
M_k -> G
G   -> W
G   -> A
G   -> Y
W   -> Y
do(A) -> Y
C   -> parameter block
M_k -> parameter block
```

Relational extension:

```text
L -> local relational precision
L -> Y
partner action -> relational observations / Y
```

Multi-mode extension:

```text
joint mode-policy vector -> Y
mode i policy -> outcome forecast used by mode j
```

Each optional dependency has one generic existence variable:

```text
Z_e in {0,1}
```

and one generic parameter posterior conditional on existence.

No direct directed edge among observation tokens is permitted. Configural or episodic evidence is induced by shared latent parents and ordinary graph dependencies. If the pairwise latent graph demonstrably cannot recover a needed joint dependency, an optional normalized higher-order latent factor may be added in a separately contracted successor; it is not part of the initial V3 grammar.

## 2.3 Context, mode, and temporal scope

Each learnable parameter block has one generic scope variable:

```text
R_b in {
  shared_global,
  cue_specific,
  context_specific,
  mode_specific
}
```

and, where temporally relevant, one generic dynamics choice:

```text
D_b in {
  static,
  discrete_recurrent_context,
  ordered_random_walk,
  one_way_change
}
```

These are grammar productions, not named psychological theories.

The V2.4 families become evaluator-side descriptions of regions of this space:

| V2 label | V3 structural readout |
|---|---|
| global down-weight | global precision or shared parameter changes; structure unchanged |
| cue-local relearning | cue-specific parameter scope |
| context split | recurrent discrete context-specific parameter scope |
| continuous drift | ordered random-walk dynamics in one context |
| change point | one-way context transition with no recurrence |
| mixed world | different parameter blocks use different scopes or dynamics |

## 2.4 One structural prior

A structure `H` is a finite grammar program. Its prior is:

```text
p(H) proportional to 2^(-L(H))
```

where `L(H)` is the frozen prefix-code length of the productions needed to describe:

- active mode and context slots;
- active edges;
- nondefault parameter scopes;
- nonstatic temporal dynamics;
- optional cross-mode interactions.

The code table is public and frozen before any scientific stage. It replaces the separate T/D/P prior, burden-lattice prior, efficacy-existence prior, configural-coupling prior, temporal-family prior, and topology prior.

This does not eliminate ordinary parameter priors. Every categorical CPT and transition row uses the same generic symmetric conjugate prior, provisionally Jeffreys / Krichevsky–Trofimov `Dirichlet(1/2)` unless the V3.0 prior-predictive audit rejects it. One structural prior and one reusable parameter-prior family replace stage-specific local priors.

## 2.5 Exact inference

For structure `H`:

```text
p(H, theta, C_1:T, M_1:K,1:T, G_1:T, W_1:T, Y_1:T, Phi_1:T, L_1:T, O_1:T | do(A_1:T))
```

is scored exactly by variable elimination, dynamic programming, and conjugate integration.

Primary V3 may use:

- decomposable local Bayesian-network scores;
- exact forward algorithms for context and mode paths;
- exact summation over the bounded structure grammar;
- exact posterior model averaging.

It may not use MCMC, variational approximations, neural amortization, or beam-search truncation in the publication result.

Every new factor must have a separately authored brute-force oracle on a reduced fixture.

## 2.6 Grow, split, and prune are readouts

The model maintains a posterior over the same frozen grammar at every time.

- **Grow:** posterior mass increases on an inactive mode, context slot, or absent edge.
- **Split:** posterior mass increases on a context- or mode-specific parameterization relative to a shared one.
- **Prune:** posterior mass decreases on an edge-present structure and increases on the corresponding edge-absent structure.

No protocol calls `grow`, `split`, `prune`, `form`, `redescribe`, or `reduce`.

# 3. Derived clinical readouts

All definitions are frozen before criterion worlds.

## 3.1 Part-like mode

Mode `k` is materially part-like when:

1. its existence / recurrent-use posterior is high;
2. its activation materially changes `q(G)`;
3. at least two of `G -> W`, `G -> A`, `G -> Y` are supported in that mode;
4. its effect survives one neutral observation;
5. the same pattern is not better explained by an external-danger-only graph.

The exact probability/BF thresholds are calibrated from public prior-predictive attainable ranges and then frozen before sealed challenges.

## 3.2 Transient threat, persistent danger, and part-like organization

These are graph classifiers, not candidates:

- **transient threat:** no recurrent mode and no persistent structure;
- **persistent external danger:** stable `W -> Y` and possibly `do(A) -> Y`, without material mode-to-identity organization;
- **part-like organization:** recurrent mode plus identity-root participation and identity-conditioned predictions.

## 3.3 Burden

For mode `k` and context `c`:

```text
burden_mass(k,c) = posterior mass on the set of identity-conditioned edges
                  {G->W, G->A, G->Y}
```

No second burden state exists.

## 3.4 Efficacy and prevented harm

Action efficacy is:

```text
q(Z_do(A)->Y = 1)
```

and its learned CPT / strength posterior.

Prevented harm is a counterfactual query derived from the same graph:

```text
p(Y(do(engage)) = harmful,
  Y(do(protect)) = safe | observations)
```

It never feeds back as an authored threat update.

## 3.5 Configural / episodic information

Configurality is the predictive-information readout:

```text
Delta_I = log p(o_joint | H) - sum_j log p(o_j | H)
```

under the same learned graph and parameters. It is evidence created by latent dependencies, not by a special format bonus or episode variable.

## 3.6 Redescription

Material redescription requires posterior support for:

- a recurrent historical context;
- present-context-specific parameters or edges;
- retained historical-context predictions;
- a present-context root/transfer consequence;
- superiority to drift, cue-local, and one-way-change regions of the same grammar.

## 3.7 Unburdening / reduction

Material reduction requires:

- the relevant mode slot remains supported;
- historical observations remain queryable;
- current or reactivated-context burden edges lose material support;
- capacity-bearing policy and perception variables remain;
- the change survives neutral evidence and a later stress probe.

Formation and unburdening therefore concern the same edge posteriors in opposite evidential directions.

## 3.8 Trust

Trust quantities are queries over the partner, causal, and outcome model:

```text
T_partner      = p(partner remains responsive | refusal, q(L))
T_coprotection = p(shared protection succeeds | q(L), q(H))
T_outcome      = p(contact is tolerable | q(L), q(G), q(C), policy)
T_efficacy     = p(protective action remains causally useful | q(Z_A->Y), q(theta))
```

They are not four independently updated trust objects.

## 3.9 Protector, exile, access, polarization

- **protector-like mode:** a mode whose policy lowers predicted cost or activation of another vulnerable mode;
- **exile-like mode:** a negatively valenced mode that is recurrently targeted by exclusion or suppression policies;
- **access:** posterior-predictive probability of vulnerable-mode observation/contact under the current joint policy;
- **polarization:** intervention on one mode’s policy increases another mode’s posterior pressure toward an opposed action through the shared outcome model;
- **coalition:** two modes’ policies mutually improve shared predicted outcomes;
- **witnessing:** vulnerable mode active, global precision broad, present context represented, root-relevant evidence delivered, and partner support available;
- **befriending:** relational observations update partner and outcome predictions in a way that changes protector-like policy.

# 7. V3.0 — exact grammar kernel

**Claim:** apparatus only.

## Gate 1 — semantic proofs

At minimum:

- every grammar-generated CPT and transition normalizes;
- code-length prior normalizes over the bounded grammar;
- edge-absence produces exact conditional independence;
- dormant mode/context slots are observationally idle;
- exact structure posterior equals brute-force enumeration;
- local score decomposition recombines to full evidence;
- `do(A)` excludes action-selection likelihood;
- shared/context/cue/mode scopes compile correctly;
- static, recurrent, drift, and one-way dynamics compile correctly;
- mixed parameter scopes coexist in one world;
- no analysis label is available to inference.

## Gate 2 — structure recovery

Generate 1,000 public worlds from grammar-sampled structures. Recover:

- active mode slots;
- active context slots;
- edge mask;
- parameter scope;
- temporal dynamics;
- exact world log probability.

Freeze accuracy, calibration, and posterior-set coverage from prior-predictive attainable ranges before criterion worlds.

## Gate 3 — composition

Required public cells:

- identity edge with no danger edge;
- danger edge with no identity edge;
- causal action edge exactly absent/present;
- cue-local plus context-specific parameters in one world;
- drift on one cue subset plus recurrent context on another;
- two simultaneous mode slots with no cross-mode interaction.

## Gate 4 — lesions

Each production deletion removes only its declared consequence.

## Gate 5 — robustness

Vary slot bounds, cue count, missingness, structure prior code length, and generic parameter concentration.

## Gate 6 — sealed apparatus challenge

An evaluator authors unseen grammar programs using only public productions. Pass requires exact construction, schema, support, structure recovery, and log-probability parity with zero new code.

# 8. V3.1 — GROW: formation, efficacy, and maintenance

Primary bounds: one optional internal mode, two external contexts, no partner.

## Scientific targets

1. transient threat, persistent danger, and part-like identity organization emerge as graph readouts;
2. action efficacy emerges as the generic `do(A)->Y` edge;
3. joint episodic information emerges from learned dependencies;
4. maintenance arises from action-controlled evidence availability;
5. no-event histories create neither modes nor edges.

## Developmental worlds

Cross:

- acute versus repeated adversity;
- low versus high control;
- narrow versus broad recursive precision;
- real external danger versus safe world;
- effective versus irrelevant protective action;
- full versus censored outcomes.

No world carries a T/D/P label into inference.

## Required open results

- danger-only worlds support `W->Y` without part-like identity structure;
- identity-bearing adversity supports mode-to-G and at least two identity-conditioned edges;
- high-control threat remains more revisable and less mode-structured;
- action efficacy is recovered only when interventions identify it;
- safe observations under a known irrelevant action reduce threat;
- censoring preserves structural odds but does not positively strengthen them;
- fixed identity removes untreated transfer;
- Delta_I is positive only when the learned graph predicts joint dependence.

## Lesions

- remove mode slot;
- remove identity edges;
- remove action edge;
- remove evidence availability control;
- sever recursive precision;
- fix G.

## Sealed challenge

A novel mixture of acute and chronic histories, real danger, sham and effective actions, and masked observations. The challenge scores graph structure and derived clinical classifications separately.

# 10. V3.3 — PRUNE: unburdening through the same edges

No new burden variables are introduced.

## Scientific targets

- the same identity-conditioned edges learned in V3.1 lose support under corrective evidence;
- mode existence, capacities, and historical observations remain;
- root revision can occur without edge pruning;
- pruning depends on the changed evidential landscape;
- imaginal do-over is an ordinary typed observation, not a reduction command.

## Required open results

- formation and reduction use identical edge identities and parameter stores;
- corrective evidence can lower current-context burden mass while the mode remains recoverable;
- historical context remains queryable;
- suggestion-only positive observations do not imitate configural corrective evidence;
- premature do-over may move edge evidence transiently but fails durability under return evidence;
- post-root-revision do-over may accelerate pruning without being necessary in every world;
- neutral observations contribute zero structural BF.

## Material reduction readout

Freeze a readout based on:

- mode retained;
- current-context burden edge mass below a low threshold;
- BF favoring the edge-absent current structure;
- stability over multiple observations;
- neutral-observation survival;
- later stress retention.

No requirement is imposed that historical-context edges vanish. A separate query reports whether the old graph remains reconstructible.

## Sealed challenge

Partial pruning, one surviving adaptive edge, premature imagery, post-revision imagery, and later stress.

# 11. V3.4 — RELATE: partner inference and recursively earned precision

Add partner state `L_t` and relational observations.

## Core change

Relational precision is not a fixed lookup table by partner label. It is derived from the learned partner model’s predictive calibration and uncertainty, then broadcast through the standing recursive precision hierarchy.

## Scientific targets

- one latent partner model explains soothing, contingency, pressure, remaining, and instability;
- local relational learning can remain local when broadcast is absent;
- co-regulation changes precision and evidence uptake, not root content;
- trust readouts cohere because they query one model.

## Required open results

Factorial regulation × root-evidence design:

- regulation absent / root evidence absent: no root revision;
- regulation present / root evidence absent: depth may rise, root BF exactly zero;
- regulation absent / root evidence present: evidence available but less admitted;
- regulation present / root evidence present: greater root uptake and transfer.

Additional controls:

- soothing but noncontingent partner;
- intrusive partner;
- unstable partner;
- partner switch;
- broadcast-off local monitor.

## Lesions

- partner→local precision;
- local→global broadcast;
- partner→outcome;
- root evidence;
- partner-state transitions.

## Sealed challenge

A switching partner with periods of soothing without contingency, reliable remaining after refusal, and intrusion. No private partner label may be available to inference.

# 12. V3.5 — PROTECT: multiple modes and policy-derived organization

Increase internal mode bound to three. No protector, exile, or topology variables are introduced.

## Core structure

Each active mode has:

- a posterior influence on identity;
- policy predictions/proposals;
- expected outcomes;
- sparse cross-mode outcome dependencies.

The exact joint policy space remains at most `3^3 = 27`.

## Scientific targets

- protector-like modes arise because their policies lower predicted vulnerable-mode cost;
- vulnerable/exile-like modes arise because they are negatively valenced and targeted by exclusion;
- access is a joint-policy consequence;
- polarization and coalition arise from cross-mode outcome forecasts;
- denied-contact aloneness updating is an ordinary observation;
- trust queries change policy without a permission state.

## Required open results

- befriend none / one / all;
- refusal met by remaining versus pressure;
- matched partner posterior at different stakes;
- exclusion versus monitoring versus engagement policy regimes;
- two versus three modes;
- opposed and allied cross-mode effects;
- partner support reaching only one mode;
- denied-contact observation delivered versus masked;
- exact-zero cross-mode lesion removes polarization while preserving single-mode learning.

## Derived topology

- independent: negligible cross-mode causal influence;
- opposed: reciprocal adverse policy influence;
- coalition: reciprocal beneficial influence.

These labels are computed after inference.

## Sealed challenge

A three-mode system with one context-dependent mandate, one partner switch, and one policy whose historical usefulness reverses.

## Developmental phase

2. partner regulation;
3. refusal opportunity;
4. noncoercive relational observations;
5. policy testing;
6. vulnerable-mode contact;

## Comparators

At minimum:

- cue-only exposure;
- protector/mode bypass;
- soothing noncontingent partner;
- unreliable partner;
- broadcast-off monitor;
- premature do-over;
- denied-contact observation masked;
- context scope disabled;
- structural pruning disabled.

## Compression tournament against Suite v2

Run V2 and V3 on common R0-generated worlds where both are expressible.

Report a Pareto profile, not one weighted score:

### Predictive adequacy

- held-out log predictive density;
- BMA or structure posterior calibration;
- regret to the known generator;
- mixed-world generalization.

### Mechanistic profile

- danger versus identity formation;
- maintenance by evidence shaping;
- depth versus dominance;
- root-mediated transfer;
- historical retention;
- same-edge reduction;
- co-regulation without root writing;
- policy-derived access;
- polarization/exiling from joint outcomes.

### Structural economy

- number of primitive latent-variable types;
- number of unique scientific factor templates;
- number of structure priors;
- number of stage-specific parameter families;
- number of frozen scientific constants;
- number of protocol-specific scientific branches;
- grammar program description length.

### Robustness

- joint parameter neighborhood;
- structure-prior sensitivity;
- missingness and cue-count sweeps;
- mixed temporal worlds;
- partner and mode-count variation.

## Minimum compression criterion

Before any V3.6 challenge, freeze:

- one structural prior only;
- no named V2 hypothesis menu in scientific state;
- no separate formation and reduction edge stores;
- no independent efficacy or episode ontology;
- no topology or trust-state ontology;
- at least 50% reduction in unique scientific factor templates and stage-specific structural constants relative to the audited V2 baseline;
- no material held-out predictive loss larger than the frozen noninferiority margin on the common-world population;
- exact preservation of load-bearing zero/pathway controls.

The noninferiority margin must be selected from public prior-predictive and V2 bootstrap uncertainty before V3 criterion worlds, not from V3 results.

## Final sealed profile

At least three challenges:

1. acute single-mode formation through full therapy;
2. chronic multi-mode protection with partner switch;
3. mixed temporal world with real danger and context-specific identity coupling.

A fourth challenge may target durability and recurrence. The profile is published whole; no sweep is required.

# 16. Stop and repair rules

## Pure software error

Standing V2 rule applies: invalidate and repeat only when no affected world or criterion was scored, the operation was already publicly declared, repair scope is frozen before results, and previously executable outputs remain bitwise identical.

## Numeric miss

Stands. It does not justify adding a special edge, changing the structure prior, increasing information length, or renaming a readout.

## Representational absence

A successor production may be added only when the missing object can be stated generically and independently of the desired clinical result.

Example permitted absence:

# 18. Resolved design tensions

## 18.1 Observation-channel edges versus latent coupling

Resolution: do not use directed observation-to-observation edges. Joint evidence should arise from shared latent parents and ordinary dependencies. A normalized higher-order latent factor is a possible later generic production only if pairwise structure demonstrably fails.

## 18.2 Named temporal families versus generic grammar

Resolution: internalize their dimensions in V3.2 as generic scope and dynamics productions, while retaining the V2.4 five-family tournament as an external benchmark.

## 18.3 Grow/split/prune operations versus exact static comparison

Resolution: the grammar is fixed. Grow, split, and prune are readouts of posterior movement, not callable operations.

## 18.4 One structure prior versus no other priors

Resolution: use one structure-code prior plus one reusable generic conjugate parameter-prior family. Preferences and precision priors remain explicit primitives.

## 18.5 One mode versus simultaneous protectors

Resolution: V3.1 begins with one optional mode; V3.5 generalizes to three binary mode slots. Simultaneous modes are irreducible for polarization and coalition.

## 18.6 Redescription versus unburdening

Resolution: both operate on context-indexed versions of the same identity-conditioned edges. Redescription scopes them; unburdening reduces their support while preserving mode and history.

No conflict between the two consultation proposals is theoretically irresolvable under these decisions.
