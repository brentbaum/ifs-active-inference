# Experiment 51 execution kickoff

Use with `experiment-51-compositional-organism-spec.md`.

## First turn: Sol only

Read the complete Experiment 51 specification. Act as evaluator and challenge custodian, not implementer.

Before any organism code is written:

1. Commit and Fable-review public declarative contract `1.0.0`, including the
   four formal schemas, trace vocabulary, analysis grammar, world/RNG semantics,
   aggregate bounds, seed-escrow convention, valid/invalid fixtures, and the
   deterministic archive convention. Bind all private material to that exact
   contract commit. Any later contract change invalidates the seal.
2. Author at least three machine-readable 51-P bundles using only the public configuration, world, protocol, and analysis schemas in the spec.
3. Ensure the set includes a novel topology, a cross-timescale composition, an ambiguous or switching world, and a selectivity challenge.
4. Author disjoint seed escrows for 51-H, 51-C, 51-P, and 51-L.
5. Add only bundle hashes, byte counts, and the escrow hash to the repository.
6. Keep all plaintext 51-P bundles and seeds outside Fable's accessible context.
7. Stop and report the seal commit. Do not reveal challenge content.

## Second turn: Fable after Sol's seal

Read the complete Experiment 51 specification and the committed seal hashes. Act as implementation orchestrator.

1. Create a fresh implementation branch from `codex/epistemic-depth-experiment-tournament`.
2. Preserve every Experiment 50 file unchanged.
3. Implement the schemas, generic graph compiler, canonical state, common observation/likelihood system, one inference/learning/policy schedule, generic protocol runner, generic evaluator, and provenance trace.
4. Do not create an assay dispatcher or protocol-specific scientific function.
5. Complete the semantic edge/mutation, exact-inference, evidence-accounting, and generic-runner gates.
6. Run only public dummy bundles and open 51-D development worlds.
7. Produce the development ledger and Stage A report.
8. Stop before strain freeze, historical escrow, composition escrow, challenge reveal, or 51-L execution.

## Third turn: Sol audit

Audit the Stage A implementation for:

- assay/challenge dispatch;
- unused configuration semantics;
- scientific operations in protocol code;
- direct transfer assignments;
- heuristic model-family classification;
- pseudo-BMR;
- independent protector gates rather than joint policy inference;
- local monitoring that cannot be selectively broadcast;
- cue and episodic evidence without a common likelihood account;
- outcome-derived repairs or moved criteria.

Return a blocking review. Fable may proceed to freeze only after all blocking findings are resolved or explicitly retained as architecture failures.
