# Canonical Terminology Card — v1

## Writing rule

> **IFS phenomenon first; formal active-inference operation second; bridge term only when it maps the two and earns a prediction.**

## Stable IFS terms

**Part, burdened part, exile, protector, burden, Self, Self-energy, blending, unblending, trust, permission, befriending, witnessing, unburdening.**

## Stable formal terms

**Generative model, latent state, prior, posterior, likelihood, policy, expected outcome, prior preference, prediction error, precision, effective precision, latent context, hyper-model, precision field, model evidence, Bayesian model comparison, Bayesian model reduction, epistemic action, information gain.**

## Stable bridge terms

**Frozen identity, identity-level precision bundle, self-state, identity root, uncaptured inference, context-held activation, Self-position, root-relevant evidence, relational prediction error, relational revision, melting, descent.**

## High-risk overloaded words

- **Trust:** protector relational forecasts only; use *precision* for confidence or weighting.
- **Root revision:** specify state inference, parameter learning, context reassignment, or structure change.
- **Registration:** replace with global availability, same-context assignment, likelihood dependence, or updating.
- **Control:** distinguish practical policy efficacy from epistemic ability to generate discriminating evidence.
- **Evidence:** specify cue-, root-, trust-, context-, or policy-relevant.
- **Architecture:** use the fast-inference/slower-learning guard.
- **Field:** reserve *precision field* for the formal vector; use *field-like awareness* only phenomenologically.

## Canonical guards

> **Formally, the frozen bundle remains a model. Functionally, fast inference proceeds within it rather than repeatedly comparing it with live alternatives; slower learning can still revise it.**

> **Relational prediction error is a subtype of root-relevant prediction error, not a separate learning currency.**

> **The gate is the current consequence of protector policy, not another internal entity.**

> **Witnessing is an IFS procedure modeled through sustained context-held activation; it is not identical to the field state or to revision.**

> **Melting is a descriptive bridge for root revision, context learning, and reduced support for compulsory coupling; it is not a separate latent process.**

> **The present account does not derive care from epistemic depth.**

## Retire or demote

**Local control model, care availability, policy capacity, functions as architecture, registration, collapsed reflexivity, maximal write/minimal test, whole-world activation, relational access, selective release.**

## Paragraph template

1. What happens clinically?
2. Which formal variables or dependencies represent it?
3. What operation changes them?
4. What distinctive consequence follows?
5. Is this implemented, interpretive, architecture-conditional, or empirically open?
