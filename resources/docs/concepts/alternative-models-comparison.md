# Alternative Models for IFS Computational Mechanisms

*Analysis note — February 2026*

---

## Four Alternative Framings

### Model A: Attractor Landscape (Dynamical Systems)

Parts as deep basins of attraction in a high-dimensional state space (physiological + cognitive + emotional + behavioral). Trauma carves deep basins. Blending = falling into a basin. Frozenness = basin doesn't reshape because you can't affect it from outside, and you're captured when inside. Therapy = controlled approach to the basin edge + reshaping (annealing, adding context dimensions).

**Strengths**: stickiness, body involvement, developmental freezing, dynamics of getting stuck/unstuck.
**Weaknesses**: purpose, permission, agentic quality of parts, why witnessing specifically.

### Model B: Hierarchical Dissociation (Vertical Integration Failure)

Parts arise from broken links between levels of a hierarchical generative model (sensory-motor → situational → narrative → meta-cognitive). Trauma breaks vertical link; lower levels run without top-down modulation. Self = Level 4 (meta-cognitive), structurally permanent. Therapy = restoring top-down influence.

**Strengths**: Self as structurally special, why witnessing works (Level 4 → Level 1 reconnection), the know/feel split (Level 3 understanding without Level 4→1 contact).
**Weaknesses**: polarization, protector permission, horizontal interactions between parts.

### Model C: Competing Policy Agents (Multi-Agent Ensemble)

Parts as separate policy-value systems sharing a world model but with different reward functions and Q-values. Gating mechanism selects which agent controls behavior. Protector permission = trust conditions on gating.

**Strengths**: protector permission, polarization, purposefulness, post-unburdening role change.
**Weaknesses**: parsimony, explaining frozenness (agents should keep learning).

**PHENOMENOLOGICAL CORRECTION**: This model predicts parts should feel like separate agents. They don't. When a part is active, it feels like *me* — full identification. The "agentic" quality only appears after partial unblending, when Self can observe the part. The IFS practice of imagining parts as children/figures is a clinical technique for creating distance (facilitating unblending), not a description of what's actually happening. This model gets the phenomenology wrong in a way that matters.

### Model D: State-Dependent Memory Networks (Reconsolidation)

Parts as emergent retrieval phenomena. No persistent part-structure — parts emerge when physiological state matches encoding state. The catch-22: memories only accessible in a state where processing is overwhelmed. Therapy = partial activation (window of tolerance) + reconsolidation encoding.

**Strengths**: body involvement, age-specific freezing, blending phenomenology, why ritual matters (rich multi-sensory encoding during reconsolidation window).
**Weaknesses**: parts as persistent phenomena (they're "just" memories), protector purpose, polarization.

**Can be expressed in Bayesian terms**: parts activate when the posterior (or expected future states) over hidden states falls within the region that the modular subgraph's priors were formed to handle. Activation = P(part_relevant | current_state) goes high when current_state resembles encoding_state. The body is involved because encoding included full physiological state — interoceptive predictions are part of the world model.

## Synthesis

No single model wins. The strongest hybrid uses:
- **Modularity** for structural account (why frozen, why witnessing = unfreezing, step-function resolution)
- **State-dependent memory** for activation and encoding mechanism (body, age, ritual)
- **Hierarchical dissociation** for why Self is special and witnessing works (vertical reconnection)

The competing agents model, despite matching IFS clinical language best, gets the core phenomenology wrong: parts don't feel like agents when active. They feel like me.
